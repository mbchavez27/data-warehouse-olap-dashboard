# Data Warehousing and OLAP System

This repository contains an end-to-end Data Warehousing, ETL, and OLAP
application project: it ingests the raw e-commerce dataset, transforms it into
a star-schema warehouse, and serves four analytical reports through a Go API
and a React dashboard.

- Setup and run instructions: [`README.md`](README.md)
- Schema, design decisions and evidence: [`docs/`](docs/)
- Report queries: [`olap/queries/README.md`](olap/queries/README.md)
